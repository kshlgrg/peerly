# Contributing

Thanks for helping improve PeerLy. Keep changes focused and test the affected area before opening a pull request.

## Quick Checklist

- Pull the latest `main` branch before starting work.
- Run frontend lint and build checks for UI changes.
- Run the backend locally for WebSocket or matching changes.
- Test text and video matching with two browser profiles when touching realtime flows.
- Update docs when commands, environment variables, or deployment notes change.
