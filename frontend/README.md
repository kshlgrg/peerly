# PeerLy Frontend

React and Vite client for the PeerLy student chat experience.

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Environment

Copy `.env.example` to `.env` for local development and set `VITE_WS_URL` to the backend WebSocket URL.

```bash
VITE_WS_URL=ws://localhost:8000/ws
```
